# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-08-12

### Added
- **Initial MVP Release** of the Quotidianity application.
- **Core Functionality**:
    - Create, view, and manage task lists with color-coded categories.
    - Add tasks to lists and mark them as complete.
- **User Interface**:
    - Implemented the "Dark Theme Premium" with a navy blue and teal color scheme.
    - Created the main user flow across three screens: Home, Add List, and List Details.
- **Architecture**:
    - Set up a modern Android project with Kotlin, Jetpack Compose, and an MVVM architecture.
    - Integrated Room database for local data persistence.
- **Internationalization (i18n)**:
    - Added support for 10 languages: English (default), Italian, French, German, Spanish, Portuguese, Polish, Russian, Turkish, and Simplified Chinese.
- **Splash Screen**:
    - Implemented a simple splash screen on app launch.
- **Testing**:
    - Added initial unit tests for the ViewModel layer.
